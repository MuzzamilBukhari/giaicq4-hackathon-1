# Module 1: ROS 2 Fundamentals

Welcome to Module 1: ROS 2 Fundamentals! This module provides a hands-on, practical introduction to ROS 2 for embodied AI and humanoid robotics. You'll learn core ROS 2 concepts, how to use `rclpy` for Python-based nodes, describe robots with URDF, manage systems with launch files, and bridge Python agents to ROS controllers.

Each lesson includes clear learning objectives and a corresponding lab. We'll also build a capstone mini-project: "Voice command → ROS action → simulated robot behavior."

**Learning Objectives:**
- Understand the fundamental architecture of ROS 2.
- Learn to create and manage ROS 2 nodes, topics, services, and actions using `rclpy`.
- Gain proficiency in describing robot kinematics with URDF.
- Master the use of launch files for orchestrating complex ROS 2 systems.
- Explore methods for integrating Python AI agents with ROS 2 robotic controllers.

Let's begin our journey into the exciting world of ROS 2!
