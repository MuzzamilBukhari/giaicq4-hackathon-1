# Setup Guides

Welcome to the setup guides for the Physical AI & Humanoid Robotics course. This section will help you prepare your development environment, whether you're using local hardware, cloud resources, or a hybrid approach.

## What You'll Configure

### Hardware Setup
Learn how to assemble and configure your robotics workstation and Jetson development kit. This includes:
- Workstation requirements and GPU setup
- NVIDIA Jetson Orin configuration
- Sensor integration (cameras, IMU, LiDAR)
- Power and connectivity considerations

### Software & Environment Setup
Install and configure all required software tools:
- Ubuntu 22.04 LTS setup (native or WSL2)
- ROS 2 Humble Hawksbill installation
- Gazebo and Unity simulation environments
- NVIDIA Isaac Sim and Omniverse
- Python development environment
- Required libraries and dependencies

### Cloud & Bridge Setup
For students without local GPU hardware or those wanting to leverage cloud resources:
- Cloud GPU instance configuration (AWS, GCP, Azure)
- Remote development workflows
- Simulation-to-hardware bridging
- Network configuration and latency optimization
- Cost management strategies

## Setup Paths

Choose the path that best fits your situation:

**Path 1: Full Local Setup**
- Local workstation with NVIDIA GPU
- Physical Jetson hardware
- Complete control and minimal latency
- Recommended for hands-on hardware experience

**Path 2: Cloud + Local Jetson**
- Cloud-based simulation and training
- Local Jetson for hardware deployment
- Balance cost and performance
- Good for limited local GPU resources

**Path 3: Full Cloud Development**
- Cloud-based development and simulation
- No physical hardware required
- Flexible and scalable
- Suitable for software-focused learning

## Getting Started

1. **Review Prerequisites**: Check the course intro for hardware/software requirements
2. **Choose Your Path**: Decide on local, cloud, or hybrid setup
3. **Follow Setup Guides**: Complete hardware, software, and cloud setup in order
4. **Test Your Environment**: Run verification scripts to ensure everything works
5. **Join Support Channels**: Get help if you encounter issues
