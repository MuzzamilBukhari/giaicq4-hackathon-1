# Decision: ROS 2 Distribution for Module 1

## Decision

We will target **ROS 2 Humble Hawksbill** as the primary distribution for Module 1 — ROS 2 Fundamentals.

## Rationale

Humble Hawksbill is a Long Term Support (LTS) release, providing stability and extended maintenance, which is ideal for a foundational learning module. This ensures that students will be learning with a widely used and supported version of ROS 2.

## Test Matrix

- **Primary Development/Testing Environment**: Ubuntu 22.04 LTS (Jammy Jellyfish)
- **Embedded/Robotics Platform Notes**: Jetson Orin / Orin Nano (Users should refer to NVIDIA JetPack documentation for specific ROS 2 Humble installation instructions on Jetson platforms.)
