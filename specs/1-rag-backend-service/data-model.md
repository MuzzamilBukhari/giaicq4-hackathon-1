# Data Model: RAG Backend Service

**Feature**: 1-rag-backend-service
**Created**: 2025-12-17

## Entity Definitions

### Query Request
**Description**: Represents a user's natural language question submitted to the RAG system

**Fields**:
- `query`: string (required) - The user's question or prompt
- `session_id`: string (optional) - Identifier for conversation context
- `metadata`: object (optional) - Additional request metadata

**Validation**:
- `query` must be 1-2000 characters
- `query` must not contain harmful content patterns
- `session_id` if provided, must be valid UUID format

### Retrieved Context
**Description**: Represents relevant document segments retrieved from Qdrant embeddings

**Fields**:
- `id`: string - Unique identifier for the document chunk
- `content`: string - The actual text content that matches the query
- `url`: string - Source URL of the documentation page
- `section`: string - Section title or heading from the source
- `chunk_id`: string - Identifier for this specific chunk
- `score`: number - Similarity score from vector search (0.0-1.0)

**Validation**:
- All fields required
- `score` must be between 0.0 and 1.0
- `url` must be valid URL format

### Response
**Description**: Represents the final output generated by the Gemini agent

**Fields**:
- `id`: string - Unique response identifier
- `answer`: string - The generated answer to the user's query
- `sources`: array of objects - List of source documents used
  - `url`: string - Source URL
  - `section`: string - Section title
  - `relevance_score`: number - How relevant this source was (0.0-1.0)
- `created_at`: string - ISO 8601 timestamp
- `model`: string - Name of the model used
- `usage`: object - Token usage information
  - `prompt_tokens`: number
  - `completion_tokens`: number
  - `total_tokens`: number

**Validation**:
- `answer` required and non-empty
- `sources` array must contain valid source objects
- `created_at` must be valid ISO 8601 format

### Chat Session
**Description**: Represents a conversation session for maintaining context (future extension)

**Fields**:
- `session_id`: string - Unique identifier for the session
- `created_at`: string - ISO 8601 timestamp
- `last_activity`: string - ISO 8601 timestamp
- `messages`: array of objects - Conversation history
  - `role`: string - "user" or "assistant"
  - `content`: string - Message content
  - `timestamp`: string - ISO 8601 timestamp

**Validation**:
- `session_id` required and valid UUID format
- `messages` array length limited to prevent excessive storage

## State Transitions

### Query Processing Flow
1. **Received**: Query Request validated and accepted
2. **Retrieving**: Context retrieval from Qdrant in progress
3. **Processing**: Gemini agent generating response with context
4. **Responding**: Response being streamed to client
5. **Completed**: Response fully delivered

## Relationships

- Query Request → (triggers) → Retrieved Context (0 to many)
- Retrieved Context → (used by) → Response (1 to many)
- Query Request → (generates) → Response (1 to 1)
- Chat Session → (contains) → Query Request/Response pairs (1 to many, future)

## Constraints

- Query requests must be processed within 30 seconds
- Maximum context retrieval: 10 document chunks per query
- Response streaming must begin within 2 seconds of processing start
- All text content must be UTF-8 encoded
